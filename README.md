## `whoami` — About Me

I'm **Christopher Honeywick Kalenge**, a Computer Science student at the **University of Dar es Salaam (UDSM), Tanzania**.

My interests sit at the intersection of software engineering, data science, and artificial intelligence. I enjoy understanding how raw data becomes useful information, how machine-learning systems learn patterns, and how software can turn technical ideas into practical products.

- 🎓 **Education:** BSc Computer Science, University of Dar es Salaam
- 💻 **Software Engineering:** Building web applications, APIs, and database-driven systems.
- 📊 **Data Science:** Exploring data profiling, exploratory data analysis, data quality, and analytical workflows.
- 🤖 **Machine Learning:** Learning model development, classification, evaluation, and computer vision fundamentals.
- 🧪 **Practical Experience:** Image annotation for a computer-vision workflow and software orchestration during practical training.
- 🚀 **Entrepreneurship:** Building CiteLoom, a platform focused on making data preparation more reliable.
